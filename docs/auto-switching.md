# 자동 전환

접속한 Wi-Fi 이름을 보고 언제 무엇으로 바꾸는지, 그리고 언제 바꾸지 않는지 적었습니다.

[← README 로 돌아가기](../README.md) · [문서 목록](./index.md)

## 켜고 끄기

메뉴의 **자동 전환** 항목으로 켜고 끕니다. 기본값은 켜짐입니다.
초기 설정이 끝나기 전에는 이 항목이 보이지 않습니다. 전환할 프로필도, 판단할 Wi-Fi 이름도 없어
켜고 끌 의미가 없기 때문입니다. 설정을 마치면 원래 값 그대로 다시 나타납니다.

## 무엇을 보고 바꾸나요

- 접속한 Wi-Fi 이름이 프로필의 `ssids` 목록에 있으면 그 프로필을, 없으면 기본 프로필(보통 DHCP)을 적용합니다
- 전환하면 **알림으로 알립니다.** 알림을 허용하신 경우입니다. 거부하셨다면 알림은 뜨지 않고 전환 내역은
  메뉴에만 남습니다 (메뉴의 자동 전환 아래에 `- 알림 꺼짐` 이 뜨고, 바로 아래 **"알림 설정 열기…"** 로 갈 수 있습니다)
- 이미 목표 구성이면 아무것도 하지 않습니다. **IP·서브넷·라우터뿐 아니라 DNS도 함께 봅니다.**
  IP만 맞고 사내 DNS가 남아 있으면 아직 적용된 것이 아닙니다 (DNS를 읽지 못한 경우는 판정에서 뺍니다)
- 한 번 맞춰진 뒤 구성이 다시 어긋나면(시스템 설정에서 직접 바꿈, 다른 도구, macOS 업데이트) **다시 적용합니다**
- **전환 권한이 갖춰지지 않았으면 아예 시도하지 않습니다.** `apply` 스크립트나 무암호 규칙이 빠진
  상태에서는 결과가 뻔합니다. 메뉴가 전환을 잠그는 상태와 같은 상태입니다. 그 사실을 메뉴에 적어 둘 뿐
  실패를 쌓지 않습니다. 권한을 다시 설치하면 다음 확인에서 바로 되살아납니다
- 전환에 실패하면 간격을 늘려 가며 다시 시도하고(10초 → 30초 → 90초 → 270초), 다섯 번 연속 실패하면 멈춥니다.
  Wi-Fi가 바뀌면 다시 시도합니다. 같은 자리에서 원인을 고치셨다면 메뉴의 **"지금 다시 시도"** 를 누르거나
  자동 전환을 껐다 켜시면 됩니다
- **켜져 있는 동안에는 메뉴에서 프로필을 고를 수 없습니다.** 항목은 그대로 보이고 지금 적용된 것에
  체크도 서 있지만, 눌리지는 않습니다. 자동이 곧 되돌릴 선택이기 때문입니다.
  손으로 다른 프로필을 쓰시려면 **자동 전환을 끄고 고릅니다.** 다시 켜면 그 자리에 맞는 프로필로 돌아갑니다
- **Wi-Fi 이름을 읽지 못하면 구성을 건드리지 않습니다.** 어디에 있는지 모르는 채로 IP를 바꾸는 것보다
  그대로 두는 편이 안전합니다
- **위치 권한이 없으면 자동 전환이 동작하지 않습니다.** macOS가 Wi-Fi 이름을 위치 정보로 취급하기
  때문입니다 ([이 앱이 요구하는 권한](../README.md#이-앱이-요구하는-권한)). 그 사실은 메뉴에 표시되고
  알림으로도 한 번 알립니다. 이름을 손으로 적어 넣을 수는 있지만, 오타 하나면 자동 전환이 조용히
  걸리지 않습니다

## 사내 Wi-Fi 이름 칸

전환할 Wi-Fi 이름은 설정 창의 **사내 Wi-Fi 이름** 칸에 적습니다 (설정 파일의 `profiles[].ssids` 에 저장됩니다).

- 사내에서 처음 열면 **지금 붙어 있는 Wi-Fi 이름이 채워져 있습니다** (고정 IP로 연결돼 있을 때만입니다.
  그 자리가 곧 그 프로필을 쓸 자리이기 때문입니다). 위치 권한을 아직 안 물은 상태라면
  그 칸 옆의 **[위치 권한 허용]** 을 누르시면 됩니다
- **등록하는 이름은 하나입니다.** 게스트망은 개방망이라 고정 IP를 쓸 이유가 없습니다.
  고정 IP가 필요한 사내 Wi-Fi 하나만 등록합니다
- 사내(고정 IP로 연결된 상태)에서는 이 칸이 **잠깁니다.** 앱이 읽어 넣은 이름이라 손댈 이유가 없고,
  실수로 고치면 값이 다 맞아도 자동 전환만 조용히 걸리지 않습니다.
  잠긴 칸은 **테두리 없이 값만** 보입니다 (적는 칸이 아니라는 뜻입니다)
- **사외(DHCP)에서는 잠기지 않습니다.** 사외에서 처음 설정하시는 분이 이름을 넣을 자리이자,
  잘못 넣은 이름을 고칠 자리입니다
- **비워 두면 자동 전환이 이 프로필을 고르지 못합니다.** 값이 다 맞아도 기본 프로필(DHCP)로 떨어지므로,
  사내에서 고정 IP가 풀리는 것으로 보입니다. 메뉴에서 직접 고르는 쓰임만 남습니다
- DHCP로 연결된 상태(사외)에서는 채우지 않습니다. 지금 붙어 있는 Wi-Fi가 사내라는 근거가 없고,
  집이나 카페 이름이 사내 프로필에 박히면 **그 자리에서 사내 고정 IP가 걸립니다**

나머지 다섯 칸을 채우는 이야기는 [설정하기](./settings.md) 에 있습니다.
