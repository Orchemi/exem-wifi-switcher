# 회사 밖에서 먼저 설치했다면

사내가 아닌 곳에서 지금 할 수 있는 것과, 사내에 가야 되는 것을 갈라 적었습니다.

[← README 로 돌아가기](../README.md) · [문서 목록](./index.md)

집이나 카페에서 설치하셔도 됩니다. **다만 지금 채울 수 있는 값은 없습니다.**

- 사내 IP·서브넷·라우터·DNS는 사내에서 확인하거나 IT에 물어야 아는 값입니다. 모른다고 해서
  빈 칸을 억지로 채울 일은 아닙니다. **[저장]은 필수 칸이 다 차고, 저장된 값과 달라졌을 때만 눌립니다**
  (앞뒤 공백처럼 표기만 다른 것은 달라진 것으로 보지 않습니다)
- **사내 Wi-Fi에 연결하면 값이 자동으로 채워집니다.** 사내 Mac은 대개 이미 고정 IP로 구성돼 있어,
  앱이 그 값과 붙어 있는 Wi-Fi 이름까지 읽어 넣습니다. **설정 창을 열어 둔 채 연결하셔도 됩니다.**
  그 자리에서 칸이 차고 [저장]이 살아납니다
- **권한 설치는 지금 해두시면 됩니다.** 장소와 무관합니다 (설정 창의 권한 섹션)
- 값을 이미 받아 두셨다면 지금 입력하셔도 됩니다 (손으로 적은 값은 자동 입력이 덮지 않습니다)

그때까지 메뉴바 첫 줄은 `초기 설정하기` 로 남고 그 아래에 `- 사내 Wi-Fi 에 연결하면 채워짐` 이 붙습니다.
빠뜨린 것이 있다는 뜻이 아니라, **아직 값을 만나지 못했다**는 뜻입니다.

값이 채워진 다음에 할 일은 [설정하기](./settings.md) 에 있습니다.
