# 업데이트할 때 생기는 일

새 버전으로 바꾸면 무엇을 다시 해야 하고 무엇이 그대로 남는지 적었습니다.

[← README 로 돌아가기](../README.md) · [문서 목록](./index.md)

새 버전으로 바꿀 때는 **앱만 바꿔 넣으면 됩니다.** 권한도 설정도 그대로 남습니다.

딱 한 번 예외가 있습니다. **서명 방식이 바뀐 버전으로 올라올 때는 위치 권한을 다시 허용해야 합니다.**

## 서명 방식이 바뀌는 그 한 번만 위치 권한이 풀립니다

위치 권한은 앱의 **코드 서명**에 매여 있습니다. 서명이 달라지면 macOS 는 그 앱을
**이름만 같은 다른 앱**으로 보고, 앞서 허용한 위치 권한을 넘겨주지 않습니다.

지금까지는 빌드할 때마다 서명이 달라져서 새 버전으로 바꿀 때마다 위치 권한이 풀렸습니다.
서명 방식이 바뀐 버전부터는 서명이 고정되므로 **그 뒤로는 풀리지 않습니다.** 바뀌는 그 한 번만
예전 서명과 달라 다시 허용하셔야 하고, 어느 버전인지는 **릴리즈 노트 맨 위에 적습니다.**

**서명에 매여 있는 것은 위치 권한뿐입니다.** 알림 권한은 앱의 **번들 식별자**에 매여 있어 남고,
전환 권한과 설정 값은 앱 밖(`/usr/local/…`)에 있어 앱을 바꿔도 영향이 없습니다.

### 풀렸을 때 다시 허용하는 방법

Wi-Fi 이름을 읽지 못하게 되고, 메뉴 머리말이 `초기 설정하기` 로, 그 아래가 `- 위치 권한 미승인` 으로 바뀝니다.
설정 창의 **권한** 항목에서 **[허용 요청]** 을 누르면 승인 창이 다시 뜹니다
(한 번 거부하신 뒤라면 **[위치 권한 열기…]** 로 시스템 설정에서 켭니다). 그 한 번으로 원래대로 돌아갑니다.

## 로그인 항목은 그대로 켜져 있습니다

앱을 바꿔도 자동 실행은 풀리지 않습니다. 위치 권한과 달리 로그인 항목은 앱의 **번들 식별자**에
매여 있어 서명이 달라져도 그대로입니다.

> 0.1.0 이전 버전에서는 앱을 바꿀 때마다
> **"'EXEM Wifi Switcher' 앱은 백그라운드에서 실행될 수 있습니다"** 알림이 한 번 떴습니다.
> 그때는 로그인 항목을 `~/Library/LaunchAgents` 에 파일로 만들었고 macOS가 그것을 백그라운드 항목으로
> 보았기 때문입니다. 지금은 로그인 항목으로 등록하므로 그 알림이 뜨지 않습니다.
> 예전 방식으로 켜 두셨다면 새 버전을 처음 실행할 때 자동으로 옮깁니다.

> 직접 빌드해서 쓰시는 경우는 다릅니다. `./scripts/build-app.sh` 로 다시 만든 앱은 만들 때마다
> 서명이 달라지므로, 그때마다 위치 권한을 다시 허용해야 합니다.

## 릴리즈 노트를 먼저 보세요

전환 권한(`sudoers`)이나 설정 파일 형식이 바뀐 버전은 앱만 바꿔 넣어서는
안 되고 설정 창의 **권한** 항목에서 **[설치]** 를 한 번 더 누르셔야 합니다. 그런 변경은
**릴리즈 노트 맨 위에 적습니다.** 적혀 있지 않으면 그럴 필요가 없는 버전입니다.
