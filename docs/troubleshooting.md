## 권한이 갖춰졌는지 확인합니다

설정 창의 **권한** 섹션이 필요한 권한 넷(전환, 설정 저장, 위치, 알림)을 한자리에 모아 보여줍니다.
항목마다 지금 상태와 왜 필요한지가 적혀 있고, 갖춰지지 않은 항목에는 조치가 붙습니다.
설치가 필요하면 **[설치]**, 시스템 권한이면 **[설정 열기]** 입니다.

창을 열 때와 다른 앱에 다녀와 돌아올 때마다 다시 확인하므로, 시스템 설정에서 허용하고
돌아오시면 그대로 반영됩니다. 같은 내용을 터미널에서 보시려면 `--diagnose` 를 쓰시면 됩니다 (판정은 같습니다).

```bash
"/Applications/EXEM Wifi Switcher.app/Contents/MacOS/EXEM Wifi Switcher" --diagnose
```

## 메뉴바에 아이콘이 보이지 않습니다

macOS 26 과 노치가 있는 MacBook에서는 새 상태 항목이 **노치에 물려** 보이지 않습니다.
macOS 는 상태 항목을 오른쪽에서 왼쪽으로 이어 붙이면서 노치를 비켜 놓지 않고, 그래서
**가장 나중에 자리 잡은 앱**이 물립니다. 자리가 부족해서가 아니며 앱은 정상 동작 중입니다.

아이콘이 가려지면 **알림으로 한 번 알려 드립니다.** 하시면 되는 것은 하나입니다.

- `⌘` 를 누른 채 아이콘을 **오른쪽으로** 끌어 옮깁니다. 노치 오른쪽은 가려지지 않습니다.
  **한 번 옮긴 자리는 다음 실행에도 남습니다** (예전에는 옮겨도 되돌아갔습니다)
- 외부 모니터(노치 없음)에서는 그냥 보입니다

> 메뉴바 아이콘을 정리하는 것은 방법이 아닙니다. 앞선 항목이 **줄면** 이 앱의 자리가
> 오른쪽으로 되돌아와 다시 노치에 물립니다.

**메뉴바가 유일한 출입구는 아닙니다.** 아이콘이 보이지 않아도 아래로 접근하실 수 있습니다.

- **앱을 한 번 더 실행하면** 이미 떠 있는 앱의 설정 창이 열립니다 (Launchpad나 Spotlight 로 다시 열면 됩니다)
- 터미널을 쓰실 수 있다면 상태를 그대로 찍어 볼 수 있습니다

```bash
# 지금 상태 확인 (Wi-Fi 이름이 읽히는지, 자동 전환이 무엇을 하려는지)
"/Applications/EXEM Wifi Switcher.app/Contents/MacOS/EXEM Wifi Switcher" --diagnose
```

## 전환이 실패합니다

메뉴에 실패 이유가 남습니다. 흔한 원인은 둘입니다.

- `sudo: a password is required` 가 보입니다. 권한 설치가 안 됐거나 풀린 것입니다.
  설정 창의 **[설치]** 를 다시 누르시면 됩니다
- 고정 IP 프로필의 DNS가 비어 있습니다. 전환을 하지 않고 멈춥니다. 설정 창에서 DNS 서버를 채워 주세요
  (비운 채로 적용하면 이름 해석이 끊기므로, 적용하지 않는 쪽이 안전합니다.
  [설정 값과 DNS](./guide.md#설정-값과-dns))

## 설정을 저장하지 못합니다

- **인증을 취소하셨습니다.** 저장되지 않았고 이전 설정이 그대로입니다. 다시 저장하시면 됩니다
- **관리자 계정이 아닙니다.** 설정 파일은 `root:wheel` 소유라 관리자 계정에서만 저장할 수 있습니다.
  관리자 계정으로 로그인하시거나, 관리자에게
  `sudo nano /usr/local/etc/exem-wifi-switcher/config.json` 을 요청하세요.
  **손으로 고칠 때는 파일 안의 `"_readme"` 블록을 지워야 합니다.** 남아 있으면 앱이 그 파일을
  "설치 스크립트가 복사한 예시 그대로" 로 보고 값을 쓰지 않습니다. 메뉴는
  `초기 설정하기 / - 아직 저장 안 됨` 으로 남고 자동 전환도 돌지 않습니다
  (`swift run exem-wifi-switcher-cli validate` 가 이 상태를 그대로 알려줍니다)
- **전환 권한을 아직 설치하지 않으셨습니다.** 저장을 처리할 스크립트가 없습니다.
  인증 창을 띄우기 전에 알려 드립니다. 설정 창의 권한 항목에서 **[설치]** 를 누르세요
- **이 Mac을 여러 계정이 씁니다.** `sudoers` 규칙은 설치를 실행한 계정 하나만 허용합니다.
  다른 계정에서 다시 설치하면 이전 계정의 무암호 전환이 끊깁니다 (그 계정에서 다시 설치하면 복구됩니다)

macOS를 크게 업데이트하면 `/usr/local` 아래 항목이나 sudoers 규칙이 정리될 수 있습니다.
설정 창의 권한 섹션(또는 `--diagnose`)에서 "전환 권한" 이 `설치되지 않음` 이나 `무암호 규칙 없음` 이면
**[설치]** 를 다시 누르시면 됩니다.

## 전환 알림이 뜨지 않습니다

**시스템 설정 > 알림** 에서 `EXEM Wifi Switcher` 를 허용해 주세요.
메뉴의 **"알림 설정 열기…"** 는 **이 앱의 알림 화면을 바로 엽니다.** 긴 앱 목록을 훑을 필요가 없습니다.
`--diagnose` 의 "알림 권한" 줄이 지금 상태를 알려줍니다.

알림이 없어도 전환은 그대로 동작합니다. 다만 **IP가 바뀐 사실을 그 자리에서 알 방법이 사라지므로**,
거부된 상태는 메뉴에 상시 표시됩니다. 무슨 일이 있었는지는 메뉴(와 `--diagnose`)에 남습니다.

## Wi-Fi 이름을 읽지 못합니다

macOS는 Wi-Fi 이름(SSID)을 위치 정보로 취급합니다. 그래서 위치 권한이 없으면 이름을 읽을 수 없습니다.
(`ipconfig` 와 `system_profiler` 는 권한과 무관하게 `<redacted>` 만 돌려줍니다.)

`--diagnose` 의 "위치 권한" 줄을 보세요.

- `거부됨` 입니다. 시스템 설정에서 허용해 주세요
- `아직 묻지 않음` 입니다. 앱을 실행하면 승인 창이 뜹니다.
  **방금 새 버전으로 바꾸셨다면 이 상태가 됩니다** ([업데이트할 때 생기는 일](./guide.md#업데이트할-때-생기는-일))
- 승인하셨는데도 이름이 비어 있으면 시스템 전체 **위치 서비스**가 꺼져 있는 경우입니다

**나중에 켜는 방법.** 설정 창의 **권한** 섹션에서 **[허용 요청]** 또는 **[위치 권한 열기…]** 를 누릅니다.
아직 묻지 않은 상태라면 승인 창이 바로 뜨고, 한 번 거부하셨다면
**시스템 설정 > 개인정보 보호 및 보안 > 위치 서비스** 가 열립니다.
이 화면은 앱 목록이라 앱을 지목해서 열 수 없습니다. **이름순** 목록에서 `EXEM Wifi Switcher` 를 찾아 켜 주세요.

권한이 없는 동안에는 설정 창의 **사내 Wi-Fi 이름** 칸이 자동으로 채워지지 않습니다.
그 사실이 칸 아래에 표시되며, 이름을 알고 계신다면 직접 입력하셔도 됩니다.
