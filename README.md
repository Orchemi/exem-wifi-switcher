# EXEM Wifi Switcher

사내 Wi-Fi에 접속하면 고정 IP(수동 구성)로, 그 밖의 네트워크에서는 DHCP로 **자동 전환**하는 macOS 메뉴바 앱입니다.

Wi-Fi 이름(SSID)을 보고 알아서 바꿉니다. **전환할 때마다 관리자 암호를 묻지 않습니다.**

- macOS 13 이상
- **터미널을 쓰지 않습니다.** 내려받아 실행하고, 앱 안에서 버튼으로 설치합니다
- 처음 준비하는 동안 관리자 인증을 두 번 받습니다: 전환 권한을 **[설치]** 할 때 한 번,
  설정 값을 **[저장]** 할 때 한 번. 그 뒤로는 값을 고칠 때만 다시 묻습니다
- 서명·공증이 없어서 처음 열 때 macOS가 한 번 막습니다. 여는 방법은 [설치](#설치) 안에 적어 두었습니다
- 소스가 공개돼 있습니다. [직접 빌드](./docs/building.md)해서 써도 됩니다

(자동 전환이 켜져 있는 동안에는 프로필 항목이 흐리게 보이고 눌리지 않습니다).</sub>

## EXEM 사내 전용입니다

범용 Wi-Fi 전환 도구가 아닙니다. **EXEM 구성원이 EXEM 사내망에서 쓰려고 만들었습니다.**

- 상대하는 네트워크는 이름이 **`EXEM` 으로 시작하는 사내 Wi-Fi** 하나입니다
- 넣어야 하는 값(고정 IP·서브넷 마스크·라우터·사내 DNS)은 **사내에서만 얻을 수 있습니다.**
  내려받아도 회사 밖에서는 채울 값이 없습니다

그래도 공개 저장소에 두는 이유는 둘입니다.

1. 이 도구는 `sudoers` 에 **암호 없이 root 로 실행되는 규칙**을 설치합니다.
   그런 것을 설치하라고 권하려면, 받는 사람이 [무엇이 어디에 놓이는지](./docs/guide.md#설치되는-항목-전부)
   읽고 [설치 버튼이 실제로 실행하는 스크립트](./scripts/install.sh)까지 직접 확인할 수 있어야 합니다.
   확인할 수 없는 것을 믿어 달라고 하지 않으려는 것입니다
2. 사내 동료가 내려받을 곳이 필요합니다

## 이 앱이 요구하는 권한

넷입니다. 무엇 하나 배경에서 조용히 가져가지 않고, 그때그때 사용자에게 묻습니다.

| 권한 | 왜 필요한가요 | 언제 묻나요 |
|---|---|---|
| **전환 권한**<br><sub>암호 없이 실행되는 `sudo` 규칙</sub> | • 전환할 때마다 암호를 묻지 않으려고 미리 등록해 둡니다<br>• 암호 없이 열어 주는 것은 프로필 이름 하나만 받는 스크립트 하나뿐이고, 그 이름도 검증합니다 | 설정 창의 **권한** 항목에서 **[설치]** 를 누를 때 한 번 |
| **설정 저장 권한**<br><sub>관리자 인증</sub> | • 저장한 값이 그대로 전환의 인자가 되므로, 설정 파일을 `root` 소유로 잠급니다<br>• [잠그는 이유](./docs/guide.md#저장할-때-관리자-인증을-한-번-받습니다) | 값을 **[저장]** 할 때마다 |
| **위치 권한** | • macOS는 Wi-Fi 이름(SSID)을 위치 정보로 취급합니다<br>• 이름을 읽지 못하면 여기가 사내인지 알 수 없습니다 | 앱을 **처음 열 때** 한 번. 설정 창보다 먼저입니다 |
| **알림 권한** | • 전환이 일어난 사실을 그 자리에서 알리는 유일한 길입니다 | 앱이 처음 알림을 보낼 때 |

- 위치는 **이 판단에만 쓰이고 저장하거나 외부로 보내지 않습니다**
- 위치 권한은 초기 설정의 필수 항목입니다. 없으면 사내 Wi-Fi 이름을 손으로 적어 넣어야 하는데,
  오타 하나면 자동 전환이 조용히 걸리지 않습니다. 그래서 갖춰지기 전까지 메뉴 머리말이
  `초기 설정하기` 로 남습니다
- 필수라고 해서 앱이 잠기지는 않습니다. 메뉴에서 프로필을 골라 **수동 전환**하는 것은 그대로 됩니다
  (다만 자동 전환은 동작하지 않습니다)
- 알림을 거부해도 전환은 그대로 동작합니다. 전환 내역은 메뉴에 남습니다
- 네 권한이 지금 어떤 상태인지는 설정 창의 **권한** 섹션 한 자리에 모여 있습니다.
  갖춰지지 않은 항목에는 조치 버튼이 붙습니다

## 설치

시작하기 전에 셋을 알고 계셔야 합니다.

- **관리자 계정이 필요합니다.** 전환 권한 설치와 설정 저장이 각각 관리자 인증을 한 번 받습니다.
  관리자가 아닌 계정에서는 설치도 저장도 할 수 없습니다
- **앱을 처음 열면 위치 권한 창이 먼저 뜹니다.** 설정 창보다 먼저입니다
- **Intel Mac에서 Homebrew가 `/usr/local` 을 소유하고 있으면 설치되지 않습니다.**
  설치 스크립트가 그 상태를 감지하고 멈춥니다. 이유는 [한계](./docs/guide.md#한계) 에 적어 두었습니다
  (Apple Silicon은 해당 없습니다)

1. **[Releases](https://github.com/Orchemi/exem-wifi-switcher/releases) 에서 zip을 내려받습니다**
2. 압축을 풀고 `EXEM Wifi Switcher.app` 을 **응용 프로그램** 폴더로 옮깁니다
3. 앱을 엽니다. 처음에는 macOS가 막으므로 아래 접힌 글
   **"처음 열 때 macOS가 막습니다"** 의 절차를 한 번 거칩니다
4. 설정 창의 **권한** 항목에서 **[설치]** 를 누릅니다.
   무엇을 어디에 놓을지 먼저 보여주고, 확인하면 관리자 암호를 한 번 묻습니다
5. 사내 **Wi-Fi 이름·IP·서브넷 마스크·라우터·DNS 서버** 를 입력하고 저장합니다.
   저장할 때 관리자 암호를 **한 번 더** 묻습니다. 이것이 마지막입니다

두 번의 인증 모두, **취소하시면 아무것도 바뀌지 않습니다.** 실패했을 때는 이유를 그대로 알리고
터미널에서 이어서 할 명령을 복사할 수 있게 해 드립니다.

<details>
<summary><b>처음 열 때 macOS가 막습니다</b> (여는 방법은 한 번만 하면 됩니다)</summary>

<br>

앱을 처음 열면 **"확인되지 않은 개발자"** 또는 **"손상되었습니다"** 라는 경고가 뜨고 열리지 않습니다.

**왜 그런가요.** Apple의 유료 개발자 프로그램(연 129,000원)에 가입하지 않아 이 앱을
**공증(notarization)** 받지 못했습니다. 공증이 없으면 macOS는 인터넷에서 내려받은 앱을 일단 막습니다.
앱에 문제가 있어서가 아니라, Apple이 확인해 준 적이 없어서입니다. 숨길 일이 아니라서 그대로 적습니다.

**여는 방법**

1. 앱을 열어 봅니다. 경고가 뜨면 **확인** 을 눌러 닫습니다
2. **시스템 설정 > 개인정보 보호 및 보안** 을 엽니다
3. 아래로 내려 **보안** 항목을 찾습니다. `"EXEM Wifi Switcher"이(가) 차단되었습니다` 같은 문구 옆의
   **[그래도 열기]** 또는 **[확인 없이 열기]** 를 누릅니다
4. 앱을 다시 엽니다. 한 번 더 묻는 창에서 **열기** 를 누르면 이후로는 그냥 열립니다

> macOS 15(Sequoia)부터는 **아이콘을 우클릭해 여는 방법으로 넘어가지지 않습니다.**
> 위의 시스템 설정 경로를 거쳐야 합니다.

**믿고 열어도 되는지 확인하고 싶으시다면.** 이 경고를 없앨 방법이 저희에게 없으므로, 대신 확인할 거리를 둡니다.

- 이 저장소의 코드를 읽습니다. 특히 [`scripts/install.sh`](./scripts/install.sh) 입니다.
  앱의 **[설치]** 버튼이 실행하는 바로 그 파일입니다
- 릴리즈 노트의 **SHA-256** 과 내려받은 파일을 대조합니다: `shasum -a 256 <내려받은 zip>`
- 아예 [직접 빌드](./docs/building.md)합니다. 직접 빌드한 앱은 이 경고가 뜨지 않습니다

터미널로 격리 속성을 지우는 방법(`xattr -d com.apple.quarantine`)도 있지만 권하지 않습니다.
그 명령은 **모든 앱에 대해** 통하는 습관이 되기 쉽고, 정작 위험한 앱을 열 때도 손이 먼저 나가게 됩니다.

</details>

  <img src="docs/screenshots/settings-window.png" width="492"
       alt="설정 창. 사내 Wi-Fi 이름(EXEM)과 IP 주소·서브넷 마스크·라우터·DNS 서버가 채워져 있고, 권한 네 항목(전환·설정 저장·위치·알림)이 모두 갖춰진 상태. 맨 아래에 '로그인 시 자동 실행' 체크상자." />
</p>

<sub>4단계와 5단계를 하는 자리입니다. 위쪽 다섯 칸에 사내 값을 넣고, 아래 <b>권한</b> 항목에서 넷이 다
갖춰졌는지(<code>설치됨</code>·<code>허용됨</code>) 확인합니다. 화면에 보이는 주소는 문서용 예약
대역(RFC 5737)이라 실제 값이 아닙니다.</sub>

**사내에서 이미 고정 IP를 쓰고 계시다면** 5단계의 다섯 칸이 모두 채워져 있습니다. 확인하고 **[저장]** 만
누르면 됩니다. 지금 붙어 있는 Wi-Fi 이름까지 함께 채워지므로, 그 한 번으로 자동 전환까지 섭니다.
회사 밖에서 먼저 설치하셨다면 [지금 할 수 있는 것과 없는 것](./docs/guide.md#회사-밖에서-먼저-설치했다면)을 보세요.

**로그인 시 자동 실행** 은 설정 창의 체크상자로 켜고 끕니다. 켜면 **시스템 설정 > 일반 >
로그인 항목 및 확장 프로그램** 의 위쪽 **"로그인 시 열기"** 목록에 `EXEM Wifi Switcher` 로 나타납니다.
켜고 끄는 최종 권한은 macOS에 있습니다. 시스템 설정에서 이 항목을 끄면 로그인해도 뜨지 않고,
그때는 체크상자 아래에 **"macOS 가 이 항목을 꺼 두었습니다"** 가 남습니다.

> 앱의 **[설치]** 버튼이 실행하는 것은 이 저장소의 [`scripts/install.sh`](./scripts/install.sh) 그대로입니다.
> 앱 번들 안(`Contents/Resources/scripts/`)에 같은 파일이 들어 있어서, 터미널로 설치한 사람과
> 앱으로 설치한 사람의 결과가 갈라지지 않습니다.
> 누르기 전에 보여주는 목록도 앱이 지어낸 것이 아니라, 그 스크립트가 `--dry-run` 으로 내놓은 내용 그대로입니다.

> 메뉴바에 아이콘이 보이지 않아도 앱은 동작 중입니다. 앱을 한 번 더 실행하면 설정 창이 열립니다.
> 자세한 것은 [메뉴바에 아이콘이 보이지 않습니다](./docs/troubleshooting.md#메뉴바에-아이콘이-보이지-않습니다) 를 보세요.

## 제거

설정 창의 **권한** 항목 옆 **[제거]** 를 누릅니다. 지울 목록을 먼저 보여주고, 관리자 인증을 한 번 받습니다.

되돌리는 것은 로그인 항목 · `sudoers` 규칙 · 권한 스크립트 두 개 · 설정 디렉터리 · 앱 설정값 ·
위치 권한 기록입니다 (하나하나가 무엇인지는 [설치되는 항목 전부](./docs/guide.md#설치되는-항목-전부) 에 있습니다).

<details>
<summary><b>앱이 열리지 않아 [제거] 버튼에 닿을 수 없다면</b> (터미널)</summary>

<br>

제거 스크립트가 앱 안에 들어 있습니다. 터미널에서 이렇게 부릅니다.

```bash
# 무엇을 지울지 먼저 보기
"/Applications/EXEM Wifi Switcher.app/Contents/Resources/scripts/uninstall.sh" --dry-run

# 실제로 지우기 (필요한 순간에만 sudo 로 승격합니다)
"/Applications/EXEM Wifi Switcher.app/Contents/Resources/scripts/uninstall.sh"
```

앱을 응용 프로그램 폴더가 아닌 곳에 두셨다면 그 경로로 바꿔 부릅니다.
**앱까지 지워 버리셨다면** 저장소를 내려받아 `./scripts/uninstall.sh` 를 쓰면 됩니다.
지우는 대상은 앱 밖에 있습니다. 두 길은 같은 파일입니다.

터미널로 제거할 때는 **로그인 항목이 빠집니다.** 그것만은 파일이 아니라 macOS가 들고 있는 기록이라
셸에서 끌 방법이 없습니다. 스크립트가 그 자리에서 어떻게 끄는지 알려 줍니다.
앱의 **[제거]** 를 쓰면 앱이 함께 끕니다.

</details>

**제거해도 남는 것** (직접 정리해 주세요)

- **앱 자체.** 응용 프로그램 폴더에서 `EXEM Wifi Switcher.app` 을 휴지통으로 옮깁니다.
  앱을 지우면 로그인 항목 기록도 macOS가 함께 정리합니다
- **알림 권한.** **시스템 설정 > 알림** 에서 `EXEM Wifi Switcher` 항목을 지웁니다.
  macOS는 이것을 명령으로 지우는 방법을 제공하지 않습니다
- `/usr/local/libexec` · `/usr/local/etc` 디렉터리. 이 도구가 만들었더라도 다른 도구가 쓸 수 있어 남깁니다

## 문제 신고와 취약점 제보

이 도구는 `sudoers` 에 **암호 없이 root 로 실행되는 규칙**을 설치합니다.
그 규칙이나 권한 스크립트(`apply` · `save-config` · `install.sh`)에서 문제를 찾으셨다면 알려 주세요.

- **창구는 이 저장소의 [Issues](https://github.com/Orchemi/exem-wifi-switcher/issues) 하나입니다.**
  비공개 신고 경로는 두지 않았습니다. 메일 주소를 공개 저장소에 적지 않기 위해서입니다
- Issues 는 공개됩니다. **사내 IP·라우터·DNS 주소·MAC 같은 값을 본문에 붙여넣지 마세요.**
  재현 절차를 적으실 때는 문서용 예약 대역(`192.0.2.x`)으로 바꿔 적어 주세요
- 사내 구성원이시라면 사내 채널로 먼저 알려 주셔도 됩니다
